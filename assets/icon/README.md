# Іконка застосунку

`slovo-icon.svg` — джерело дизайну (256×256, viewBox `0 0 256 256`).
`png/slovo-*.png` — растрові експорти, по одному на розмір.

`..\..\Slovo_Icon.ico` у корені проєкту зібрано з цих PNG і підключено через
`Icon_MainIcon` у `Slovo.dproj`. Delphi при збірці розкладає його в `Slovo.res`
як `MAINICON`, звідки Windows бере іконку і для вікна, і для файлу EXE.

## Формат .ico

| Розмір | Формат | Джерело |
|---|---|---|
| 16, 20, 24, 32, 40, 48, 64, 128 | BMP 32-bit | `png/slovo-N.png` |
| 96 | BMP 32-bit | згенеровано з `slovo-256.png` (Lanczos) |
| 256 | PNG | `png/slovo-256.png` |

BMP для малих розмірів, а не PNG, — свідомо: PNG-стиснені записи в `.ico`
Windows читає лише з Vista, і деякі шляхи оболонки та старіші версії Delphi
на них спотикаються. На 256×256 PNG, навпаки, є нормою — інакше один цей
запис важив би 256 КБ.

Розміри 20, 40, 96 потрібні для масштабування DPI (125 %, 250 %, 150 %):
без них Windows розтягує сусідній розмір і іконка стає мильною.

## Перезбирання .ico

Після зміни SVG перегенеруйте PNG-набір, потім зберіть `.ico` будь-яким
редактором іконок, що вміє зазначений вище формат (IcoFX, GIMP,
ImageMagick + ручне складання контейнера).
